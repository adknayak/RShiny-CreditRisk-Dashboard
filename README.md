Description: This is an R Shiny based dashboard that has visualisation, and an
LGD Estimator. There is also a document reader in the last tab. 
Feel free to play around and explore the dashboard. 

How to Run:
The app.R file is the file with the dashboard. Simply run the script and then 
launch the app. The development was done using R Studio. 

What are the other Files?
Some are blank scripts to check the original datasets. 
The .rds files are there to save the findings from the machine learning
algorithms so that anyone who downloads the app in the future can simply launch
the app without needing the models to run calculations from scrath. 
Other scripts are the workings and the relevant machine learning models that 
are the behind-the-scenes calculation engine for the dashboard output.
